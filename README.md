# NSU 智慧教育学习助手

适用于学校的 `study.nsu.edu.cn`，版本 0.3.1。安装文件是 `nsu-study-helper.user.js`，无需构建或安装 Node.js。

这是正常播放视频的油猴助手，不伪造学习时长或完成记录，不自动答题，不跳过验证。

## 安装与首次使用

从 [GitHub Releases](https://github.com/L1Xu4n/nsu-study-helper/releases/latest) 下载 `nsu-study-helper.user.js`，或使用[脚本下载链接](https://github.com/L1Xu4n/nsu-study-helper/releases/latest/download/nsu-study-helper.user.js)。如果浏览器没有自动弹出油猴安装页，按下面步骤导入。

1. 在 Edge 中打开油猴 Tampermonkey 的管理面板。
2. 进入“实用工具”，找到“从文件导入”，选择本目录的 `nsu-study-helper.user.js`，核对脚本名称和域名后安装。
3. 刷新学校课程详情页和已经打开的资源页。右上角应出现“NSU 学习助手”。
4. 保持“试运行”勾选，点击“检查”或“开始”，核对候选视频。试运行不会点击课程按钮，也不会控制已在播放的视频。
5. 首次实际运行把“最多”设为 1，关闭其他正在播放的学习标签页，再取消“试运行”并点击“开始”。
6. 确认这一个视频在平台目录显示“已完成”后，再增加队列数量。

## 多开与并发

- 更新到 0.3.1 后，先停止旧脚本，并刷新所有课程/资源标签页，避免新旧版本混用；面板标题旁应显示 0.3.1。
- 自动队列：在课程目录把“队列并发”设为 2–5，取消试运行后开始。“最多”是本次总数，“队列并发”是同一批同时播放的数量；默认仍为 1。
- 要自动继续下一项，必须勾选“自动续播下一视频”。旧设置若关闭，新版不会擅自替你打开；运行时会明确提示未开启。
- 脚本会为每个视频打开独立标签页。平台明确确认一项学习完成后，脚本确认弹窗、关闭该队列窗口，并自动补充下一项，不打断其他仍在播放的视频。
- Edge 可能只允许一次打开一个新窗口。此时点面板中的“打开待播”逐个打开，或自行设置允许本站弹窗。脚本不会自动更改浏览器权限。等待项超过 120 秒仍未接管会标记失败。
- 手动多开：分别打开不同资源页，各自取消试运行并点击开始。手动模式不受队列互斥锁限制，但全部脚本播放器合计最多 5 个，同一视频仍禁止重复启动。
- “停止”在目录页停止本批队列，在资源页只停止当前视频；“全部停止”广播给所有运行中的本脚本页面，包括独立手动多开的视频。
- 一项真实媒体故障只暂停该项，其他项可以继续完成；存在失败项时不再自动补充新视频。登录失效或本人验证会停止整批。
- 学校服务不稳定时，先用 2 个并发观察。这里支持正常并行播放，不承诺学校一定接受并发进度，也不屏蔽平台自身的暂停或校验。

## 自动确认与续播

1. 平台可能在异步请求之后才打开资源页。脚本逐项等待实际开窗地址，写入任务标识；新窗口加载出播放器后自动开始，不需要再点一次开始。
2. 视频真实结束且出现“你已完成该视频学习,学习状态已更新！”时，识别为平台完成凭据，点击弹窗中可见的“关闭”或确认按钮。
3. 完成记录先保存到脚本任务，再关闭其专用队列窗口；已勾选自动续播时，目录补充下一项。
4. 没有明确成功提示时，不凭播放结束认定完成。待活动视频结束后，仍回目录按文字和百分比核对，保留有限退避重试。

只关闭由队列关联、资源路径和专用窗口名都一致的窗口。手动打开并单独启动的视频页可以自动确认成功提示，但不会自动关闭，也没有可续播的目录队列。验证码、登录提示及其他未知确认框不会自动点击。

## 目录刷新与恢复

- 运行中短暂刷新课程目录，不再等同于点击停止。脚本保存本标签页的队列快照，并在 90 秒内恢复原有视频任务，不重新打开已关联的视频。
- 运行锁暂时未释放时会短暂重试，不会因为第一次获取失败就丢掉恢复记录。
- 点击“停止”或“全部停止”、超过运行时限、关闭目录超过 90 秒，都不会自动恢复。运行期间应保留一个目录页。
- 目录刷新时还没获得地址的开窗请求会被取消，避免把迟到请求关联错视频；其他已关联任务可以继续。
- 刷新资源视频页仍会停止该资源。升级脚本时请先停止旧版，再刷新所有相关页面，从目录重新开始一次；旧版已经取消的队列无法凭空恢复。
- 新接管的视频若已经播完，会进入平台完成核对，不会再次播放，也不再以“视频已经结束”为错误停止。
- 播放器到末尾不代表平台已记入完成。目录仍显示“学习中”或不足 100% 时，脚本会按已有策略等待核对，不强行标记完成。

如果没有面板，检查脚本是否启用、油猴是否有本站访问权限及浏览器是否允许用户脚本运行。
安装后请先用单个视频验证自动播放和平台完成记录，再增加并发。

## 已实现

- 读取当前已加载目录中的视频、名称、百分比、开放状态及完成文字。
- 按视频名称筛选，按页面现有顺序播放；默认最多 5 项、90 分钟，可调整为 1–50 项、5–180 分钟。
- 精确跳过“已完成且 100%”的资源；同名资源、未知状态或矛盾完成状态会停止。
- 通过原生“去学习”按钮打开资源，每个视频有独立任务和窗口名，避免旧窗口的关闭动作误伤新视频。
- 使用真实 HTML5 视频播放，不修改 `currentTime`、不强制倍速、不构造学习上报请求。
- 可选静音；停止时恢复脚本改动前的静音设置。保留平台原有暂停和可见性规则。
- 手动“停止”、跨标签停止、播放器卡顿、登录失效和本人验证保护。
- 单视频模式：在资源页取消试运行后点击“开始”，只处理当前视频，不自行猜测下一节。

## 平台不稳定时

- 播放页显示请求错误但媒体仍在正常播放时继续观察，不点击“重新播放”。真实媒体错误、原生暂停、45 秒不前进或本人验证仍会停止；错误文字本身不再等同于播放失败。
- 明确完成提示可以直接确认并续播。没有提示时，自然结束后等待 8 秒，再由目录端在活动视频结束后等待 10 秒刷新核对；这期间持续监听迟到的完成提示。
- 目录尚未确认完成：最多额外等待 15、30、60 秒，各刷新一次。仍未确认就停下，不跳过、不重复播放、不循环刷新。
- 资源页 120 秒内未关联、播放器 20 秒内未出现、播放启动 15 秒无响应、视频 45 秒不前进，都会停止。
- 原生按钮点击后 30 秒仍无法获得开窗地址会停止，并要求刷新目录后重试，以免把迟到请求关联到下一项。
- 手动单视频结束后的提示监听持续到本次运行时限，不会在两分钟后静默退出。
- 浏览器节流、休眠或后台暂停可能让队列停下。脚本不伪装前台状态。

播放结束只意味着媒体结束。最终是否计入考核，必须以平台目录和学习统计为准。

## 适配范围与限制

- 已只读检查真实 Edge 页面的 `.resItem`、`.file-name__span`、`.stateLabel`、`[role="progressbar"]`、`video#dPlayerVideoMain`。
- 仅匹配本校域名，不会在超星 `mooc1.chaoxing.com` 页面运行。本脚本不是超星通用脚本。
- 仅支持已加载、状态为“进行中”且有唯一“去学习”按钮的视频卡片；不自动翻页、切课程、展开未加载目录或处理文档/考试。
- 队列兼容原生按钮同步或异步调用 `window.open`；实际开窗地址关联后立即恢复原函数，关联过程逐项串行、视频播放仍可并发。等待时手动点其他学习按钮会取消自动关联。同页路由、缓存的原生开窗函数或完全不同的打开机制仍可能需要适配。
- 为关联新页面，资源 URL 增加一次性 `#nsu-study-helper=...` 片段，并使用专用窗口名。路由清理 hash 后可通过窗口名识别；二者是任务标识，不是账号认证令牌。每资源原子锁避免重复播放，播放槽将脚本控制的媒体限制在 5 个以内。
- 不移除原生 `noopener/noreferrer` 等安全选项，不更改弹窗权限。自动续播需要浏览器允许本站打开窗口；若浏览器阻止开窗或关闭，会保留提示，不会伪报操作成功。
- 只监测已知的可见提示，不可能识别所有静默上报失败。刷新核对不能保证修复服务端故障。
- 真实平台上的窗口打开方式、扩展执行环境、自动播放许可和最终进度入账仍待安装后验证。

## 隐私与文件

只读写前缀为 `nsu-study-helper:v1:` 的本地存储键，保存设置、任务名称、资源路径和任务状态。0.3.1 继续保留旧设置键和带 `v2` 后缀的独立任务、控制、停止命令键；更新时需要停止旧实例并刷新页面，避免混用。目录刷新恢复记录放在当前标签页的会话存储里。停止后取消恢复记录。脚本自身不读取账号密码、Cookie 或认证令牌，不上传数据，不引入远程脚本或统计服务。

| 文件 | 用途 |
| --- | --- |
| `nsu-study-helper.user.js` | 唯一需要安装到油猴的文件 |
| `FUNCTIONS.md` | 每个命名函数的中文说明 |
| `tests/helper.test.cjs` | 解析、状态机、故障和并发回归测试 |
| `tests/demo-server.cjs`、`tests/fixture.js` | 仅本机可访问的合成页面和合成媒体 |
| `package.json`、`package-lock.json` | 开发测试命令与固定依赖 |
| `LICENSE`、`CHANGELOG.md` | 开源许可证和版本更新记录 |

## 开发检查

在当前目录执行：

```cmd
npm ci --ignore-scripts
npm test
npm run check
npm run demo
```

本地测试入口是 `http://127.0.0.1:8765/`。端口占用时设置另一个 `PORT`；不会占用公网地址。
测试页媒体是合成状态，不代表真实视频播放或学校进度已经验证。
